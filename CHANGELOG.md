# Changelog

## 1.1.2

- Declare the Accept header type property explicitly for PHP 8.2 and newer.

## 1.1.1

- Handle requests with no content-type or content-length headers without PHP 8 deprecations.

## 1.1.0

- Add support for PHP 8.1 through PHP 8.5.
- Retain support for PHP 7.4 while explicitly excluding PHP 8.0.
- Require Wedeto Util 1.1.1, IO 1.1, and FileFormats 1.1 or newer from their compatible 1.x lines.
- Update development dependencies to Wedeto Log 1.1, DB 1.1, and PHPUnit 9.6.33 or newer.
